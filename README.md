# Деловой журнал

Мобильная PWA для малого бизнеса. Пока это оболочка: обзор, календарь, клиенты, финансы и аккаунт. Запись на интервалы, учёт клиентов, оплат и долгов появятся на следующем этапе.

## Структура

```text
src/
  main.tsx                    # точка входа
  app/
    App.tsx                   # сборка страниц
    components/               # оболочка приложения
    hooks/                    # URL, заголовок, сброс прокрутки
    enums/                    # пути разделов
    router/                   # регистрация и lazy-загрузка страниц
  modules/
    common/
      components/             # общий UI, пустое состояние, PWA, ErrorBoundary
      hooks/                  # управление обновлением PWA
      config/                 # окружение и инициализация i18next
      services/               # применение и хранение настроек
      enums/                  # язык и тема
      types/                  # общие контракты
      utils/                  # cn
      styles/                 # Tailwind и два набора токенов
    account/
      pages/                  # страница аккаунта
      components/             # формы входа и профиля
      hooks/                  # сессия, вход, состояние профиля
      api/                    # AuthApi, ProfileApi
      services/               # создание Supabase-клиента
      adapters/               # Profile.fromRaw/toRaw
      enums/                  # состояние загрузки профиля
    overview/                 # страница обзора и иллюстрация
    calendar/                 # страница календаря
    clients/                  # страница клиентов
    finances/                 # страница финансов
```

Направление зависимостей: `app → доменные модули → common`. Домен не импортирует `app` или внутренности соседнего домена. Страницы и компоненты отвечают за разметку, хуки — за React-состояние и эффекты, API — за запросы, адаптеры — за преобразование данных. Stores появятся только при необходимости состояния, общего для нескольких экранов.

Все внутренние импорты, включая динамические и CSS, абсолютные через `@/` (`src/`). Переменные окружения читаются только в `modules/common/config/env.ts`; настройки генератора UI обновлены в `components.json`. Новые слои и папки создаются по мере появления кода, не заранее.

## Профиль

Drizzle-схема: `db/schema.ts`, конфиг генерации — `drizzle.config.ts`. SQL-миграций пока нет. Когда они понадобятся, `npm run db:generate` создаст их в `db/migrations` без подключения к базе. Схема сама по себе ничего в Supabase не создаёт. Перед применением будущей миграции проверьте SQL, RLS и явно задайте права таблицы: `SELECT`, `INSERT`, `UPDATE` для `authenticated`, без доступа для `anon`.

`id` — ID пользователя из Supabase Auth. Остальные поля nullable: `name`, `telegram_username`, `theme` (`light`, `dark`), `language` (`en`, `tg`, `ru`). RLS разрешает пользователю читать и менять только свой профиль.

Адаптер `src/modules/account/adapters/Profile.ts` преобразует отсутствующие поля и `null` в пустые строки, светлую тему и английский язык. При сохранении пустые имя и Telegram преобразуются обратно в `null`. Telegram хранится без `@`; для уведомлений позже потребуется бот и получение `chat_id` после `/start`.

## Стили

Стили компонентов — только Tailwind CSS v4, через utility-классы. `src/modules/common/styles/index.css` содержит импорты, настройку `dark`-варианта и `@theme inline`, без собственных классов компонентов и `@apply`.

Два набора токенов:
- `src/modules/common/styles/themes/light.css` — светлая тема по умолчанию;
- `src/modules/common/styles/themes/dark.css` — тёмная тема, включается классом `dark` на `<html>`.

В компонентах используются семантические классы (`bg-background`, `text-foreground`, `border-line`); цвета и тени меняются в файлах тем. Цвет панели PWA берётся из токена `--theme-paper`.

## Языки и тема

Используются `i18next`, `react-i18next` и `i18next-http-backend`. Переводы и названия языков — в `public/locales/{en,tg,ru}/translation.json`. Английский — язык по умолчанию и fallback. JSON включены в офлайн-кэш PWA.

Выбор темы и языка сохраняется через форму профиля. При загрузке профиля настройки применяются к интерфейсу; локально кэшируются только тема и язык, чтобы восстановить оформление при следующем запуске. Выход сбрасывает настройки к дефолтам. Свежие серверные настройки загружаются при открытии аккаунта. Сохранение профиля пока требует сети; RxDB не подключена.
